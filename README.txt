JOM BATOKOK WEBSITE
===================

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder jom_batokok_website.
3. Klik dua kali index.html untuk membuka website di browser.
   (Disarankan menggunakan VS Code + ekstensi Live Server untuk pengembangan.)

Teknologi:
- HTML5
- CSS3
- JavaScript vanilla

Fitur:
- Responsive untuk desktop, tablet, dan ponsel.
- Navigasi mobile.
- Filter kategori menu.
- Animasi reveal saat halaman digulir.
- Tombol WhatsApp dan Instagram.
- Kartu cabang dengan tautan pencarian Google Maps.
- Jam operasional tiga cabang.

Catatan data:
- Harga menu ditulis dalam format ribuan rupiah (contoh 26K = Rp26.000), sesuai konfirmasi.
- Nomor WhatsApp menggunakan 0897-9797-799 sesuai persetujuan pengguna.
- Lokasi Galaxy ditulis sesuai materi: "Galaxy Bekasi, RSN5 29".
- Link peta merupakan tautan pencarian berdasarkan alamat yang tersedia; verifikasi pin lokasi sebelum dipublikasikan.
- Foto menu merupakan crop dari poster menu yang dikirim pengguna. Beberapa item berbagi foto representatif dari kategori yang sama.
- Google Fonts membutuhkan koneksi internet. Website tetap dapat dibuka tanpa font eksternal.
